Digit Recognizer

A C++17 MNIST digit OCR tool. Images are preprocessed to a 28×28 vector, then classified by a 3-layer MLP (CPU, or optional ROCm/HIP). Four CLI commands cover train, test, single-digit predict, and multi-digit predict.

I/O CPU preprocess Network Optional GPU

PNG/JPEG/BMP image, or MNIST IDX files under data/

MLP

CLI

Four commands

train

MNIST train set→ SGD epochs→ digit_model.bin
  • Default: 10 epochs, batch 32, lr 0.005
  • He init, cross-entropy, 784→256→128→10

test

Load model→ MNIST test set→ Accuracy %
  • 10,000 labeled 28×28 images
  • Reports overall test accuracy

predict

Image or folder→ Preprocess→ One digit
  • --infinite loops random files until stop
  • Prints digit, confidence, all 10 probs

predict-multi

Wide image→ Split on gaps→ Digit string
  • Vertical whitespace segments characters
  • Each crop runs the same recognizer

Image preprocessing (predict path)

1Load

Any size, RGB or gray via stb_image

2Grayscale

0.299R + 0.587G + 0.114B

3Auto-invert

If border is bright, invert to MNIST white-on-black

4Crop

Tight bounding box around ink

5Resize

Aspect-preserving bilinear into 20×20

6Center

Place 20×20 digit on 28×28 canvas

7Normalize

Bytes → doubles in [0, 1], length 784

Network

Input 784 · 28×28
Hidden 1 256 · ReLU
Hidden 2 128 · ReLU
Output 10 · Softmax

Compute dispatch

CPU (default Windows build)

CMake without ENABLE_HIP. Forward and backprop stay in neural_network.cpp.

  • Matvec, ReLU, softmax, SGD on host
  • --gpu logs that HIP was not built

GPU (Linux, -DENABLE_HIP=ON)

Six HIP kernels in gpu_kernels.hip, linked with hip::device / hip::host.

  • matvec, relu, softmax, output_delta, backprop_delta, update_weights
  • Optional --gpudelay / --gpumem for profiler stress
